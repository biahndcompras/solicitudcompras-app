# Manual de uso — Coordinador de Compras
**Portal de Compras BIA · Guía breve para el equipo de Compras**

> Objetivo: atender solicitudes, cargar cotizaciones, generar comparativas y enviarlas al solicitante.

## 1. Ingreso
1. Entra a `/panel` con tu **correo y contraseña** (te los proporciona el administrador).
2. Verás tu **bandeja**: solicitudes asignadas a ti, filtrables por estado
   (Activas · Esperando cotizaciones · Esperando decisión · Cerradas).

## 2. Atender una solicitud
- Cada fila muestra: referencia, solicitante, necesidad, categoría, **semáforo** y **tiempo de atención**.
- Abre la solicitud para ver el detalle completo (solicitante, respuestas, fechas).

## 3. Cargar cotizaciones
1. En la pestaña **"07 · Cotizaciones"**, selecciona el proveedor base y carga el archivo (PDF/DOCX) de su oferta.
   - El sistema **extrae automáticamente** datos: valores, impuestos, plazos, forma de pago.
   - El **archivo original se guarda** para adjuntarlo al solicitante.
2. Revisa la **confianza de extracción**: los campos con baja confianza se marcan para verificación manual.
3. Si el archivo no se pudo leer, puedes **cargar los datos manualmente**.
4. Edita los valores si es necesario antes de comparar.

## 4. Comparativa y recomendación
1. Con al menos 2 cotizaciones, genera la **comparativa**.
2. Revisa **discrepancias, pros y contras** (incluye el **ahorro potencial** de cada opción) y el **proveedor sugerido** por el sistema.
3. En **"09 · Recomendación"** escribe **tu recomendación** (siempre la decisión humana manda) y envíala al solicitante.
   - El sistema **adjunta las cotizaciones originales** al correo para que el solicitante las vea.

## 5. Seguimiento
- Las solicitudes en "Esperando decisión" muestran la **decisión del solicitante** cuando llega.
- Cuando el solicitante decide, la solicitud se **cierra** y lo sabes por el estado.

## 6. Re-cotización
- Si el solicitante cambia la cantidad o el detalle tras cotizar: edita la solicitud y **re-cotiza** con el proveedor original. Las cotizaciones anteriores quedan en el historial.

## 7. Cancelaciones
- Puedes **cancelar** una solicitud desde el detalle si corresponde (queda registrado como CANCELADA).

## Dudas frecuentes
- **¿Puedo ver solicitudes de otro comprador?** Solo las tuyas (el administrador puede reasignarte).
- **¿El sistema decide por mí?** No: sugiere; la recomendación final es tuya.
