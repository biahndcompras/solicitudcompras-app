# Manual de uso — Solicitante
**Portal de Compras BIA · Guía breve para quien solicita una compra**

> Objetivo: crear una solicitud de cotización en minutos y darle seguimiento sin necesidad de contraseña.

## 1. Crear una solicitud
1. Abre el enlace del portal (ej. `https://solicitudcompras-app.vercel.app`).
2. Captura tu **correo institucional**, **nombre** y **área/departamento**. En solicitudes posteriores tu correo se recuerda.
3. Escribe el **título** (ej. "Sombrillas brandeadas para activación") y la **descripción** de lo que necesitas.
4. Selecciona la **categoría** (ej. "Mercadeo y publicidad") y el tipo **producto / servicio**.
5. Indica **para cuándo lo necesitas**. Si el plazo es muy corto, el sistema te lo advierte.
6. El asistente **clasifica** tu solicitud (Cotización / Información / Propuesta) y te hace preguntas para detallarla.
   - Puedes **usar las sugerencias seleccionables** o escribir tu propia respuesta.
   - Si no sabes una respuesta, marca **"No lo sé"**.
7. En el resumen, elige **a qué comprador** va dirigida la solicitud (según tu categoría, se preselecciona el idóneo).
8. **Envía la solicitud**. Queda registrada con una referencia única.

## 2. Dar seguimiento
- Usa **"Mis solicitudes"** con tu correo para consultar todas tus solicitudes.
- Cada una muestra un **semáforo**: verde (a tiempo), amarillo (en riesgo), rojo (retrasada respecto a la fecha requerida).
- En el detalle ves el **progreso** por etapas (creada → en cotización → comparativa → tu decisión → cerrada).

## 3. Decidir (comparativa lista)
- Cuando Compras prepare el comparativo, recibirás un **correo con el enlace**.
- Abre el enlace, revisa las opciones (y adjuntos de las cotizaciones originales) y **decide** con un clic.
- Tu decisión queda registrada y llega de vuelta al comprador.

## 4. Consejos
- Guarda el **PDF** de tu solicitud si lo necesitas (disponible tras confirmar el envío).
- Si ya no necesitas el proceso, contacta a Compras para cancelarlo.

## Dudas frecuentes
- **¿Debo crear una cuenta?** No: solo usas tu correo para "Mis solicitudes".
- **¿Puedo modificar una cantidad después?** El comprador puede re-cotizar por ti; pídelo por correo o en la reunión con Compras.
- **¿Esto ya compra?** No: una vez decidido, Compras continúa con la orden de compra en los sistemas internos.
