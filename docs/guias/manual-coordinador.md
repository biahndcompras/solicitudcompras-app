# Manual de uso — Coordinador de Compras
**Portal de Compras BIA · Guía breve para el equipo de Compras**

> Objetivo: atender solicitudes, cargar cotizaciones, generar comparativas y enviarlas al solicitante.

## 1. Ingreso
1. Entre a `/panel` con su **correo y contraseña** (se los proporciona el administrador).
2. Verá su **bandeja**: las solicitudes asignadas a usted, filtrables por estado
   (Activas · Esperando cotizaciones · Esperando decisión · Cerradas).

## 2. Atender una solicitud
- Cada fila muestra: referencia, solicitante, necesidad, categoría, **semáforo** y **tiempo de atención**.
- Abra la solicitud para ver el detalle completo (solicitante, respuestas, fechas).

## 3. Pedir información al solicitante
Antes de cotizar puede faltarle un dato que solo el solicitante tiene (una medida exacta, una
foto de referencia, una confirmación de material).

1. En el detalle, use **"Pedir información"**.
2. Escriba una o varias preguntas. Si la respuesta corresponde a un campo del formulario,
   **átela a ese campo**: así queda guardada donde el RFQ la usa.
3. El solicitante recibe un correo y responde desde el portal.
4. Su respuesta aparece en el detalle, en el bloque **"Preguntas al solicitante"**.
5. La solicitud **no cambia de estado** mientras espera. Si el solicitante no responde en 3 días,
   el sistema le manda un recordatorio a usted.
6. Puede pedir varias rondas: la anterior se cierra cuando responde.

## 4. Cargar cotizaciones
1. En la pestaña **"07 · Cotizaciones"**, seleccione el proveedor base y cargue el archivo (PDF/DOCX) de su oferta.
   - El sistema **extrae automáticamente** datos: valores, impuestos, plazos, forma de pago.
   - El **archivo original se guarda** para adjuntarlo al solicitante.
2. Revise la **confianza de extracción**: los campos con baja confianza se marcan para verificación manual.
3. Si el archivo no se pudo leer, puede **cargar los datos manualmente**.
4. Edite los valores si es necesario antes de comparar.

## 5. Comparativa y recomendación
1. Con al menos 2 cotizaciones, genere la **comparativa**.
2. Revise **discrepancias, pros y contras** (incluye el **ahorro potencial** de cada opción) y el **proveedor sugerido** por el sistema.
3. En **"09 · Recomendación"** escriba **su recomendación** (siempre la decisión humana manda) y envíela al solicitante.
   - La recomendación es **obligatoria**: el sistema no la deja enviar vacía.
   - El sistema **adjunta las cotizaciones originales** al correo para que el solicitante las vea.

## 6. Seguimiento
- Las solicitudes en "Esperando decisión" muestran la **decisión del solicitante** cuando llega.
- Cuando decide, recibe un **correo** y el estado cambia a cerrada.
- Si el solicitante marca **"ninguna me sirve"**, la solicitud **vuelve a usted** para reevaluar;
  no se cierra.

## 7. Re-cotización
- Si el solicitante cambia la cantidad o el detalle tras cotizar: edite la solicitud y **re-cotice**
  con el proveedor original. Las cotizaciones anteriores quedan en el historial.
- También puede usar **"Reabrir cotizaciones"** para volver la solicitud a esa etapa.

## 8. Cancelaciones
- Puede **cancelar** una solicitud desde el detalle si corresponde (queda registrado como CANCELADA).
- Las cotizaciones ya cargadas **se conservan**: sirven para saber qué se pidió y cuánto costó cotizar.

## Dudas frecuentes
- **¿Puedo ver solicitudes de otro coordinador?** Sí. Todos los coordinadores ven todas las
  solicitudes; la bandeja muestra primero las suyas, y puede abrir cualquiera.
- **¿El sistema decide por mí?** No: sugiere; la recomendación final es suya y es obligatoria.
- **¿Puedo reasignar una solicitud?** Eso lo hace el administrador.
